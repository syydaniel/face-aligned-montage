# 07 合规与隐私

## 平台规则（中国大陆平台，2026 年）

- **AI 生成内容要主动声明。** 依据《人工智能生成合成内容标识办法》，微信在 2025 年 8 月公告：发布 AI 生成合成的内容时，要主动声明，不得删除或篡改平台加的标识。配音和配乐是模型生成的，发布时勾选「内容由 AI 生成」，画面上也一直标着"AI 配音 · AI 配乐"。
- **"非真人自动化创作"。** 微信公众平台运营规范 2026 年 3 月 27 日起明确：公众号和服务号不能用 AI、脚本、接口等方式代替真人完成创作和发布，也不能传播这类自动化创作的教程或服务。报道称规则不否定把 AI 当辅助工具。所以：
  - 讲的是你自己的创作过程和判断，AI 是工具；
  - 标题和文案不用"教程、一键、全自动、批量"这类字眼；
  - 旁白里说清楚哪些决定是你做的。
- **互动引导。** 不用"点赞抽奖、转发领取"这类带奖励的引导。问一个具体的问题，再给关注一个理由（下期讲什么）。
- **站外导流。** 视频和文案里不放链接，不提其他平台。

## 素材隐私

- **只留本人。** 流水线第 2 步用一张参考正脸做身份过滤；照片里只要有另一张不小的脸，整张丢掉。成片里不会出现别人。
- **地点。** 不在画面上写地名。封面用关键点挑一帧眼睛对得最准、背景没有可辨认地标的画面。素材背景本身的地标，发布前自己决定要不要保留。
- **文件名。** 相机文件名带拍摄时间。剪辑表、素材清单这类数据不要公开。

## 这个仓库排除了什么

- 所有视频、照片、音频、配音参考音、生成的配乐、渲染帧。
- 所有由素材生成的数据：关键点、候选池、剪辑表、增益表、身份样本、素材清单。
- 模型权重（用 `scripts/download_models.sh` 下载）。
- 所有个人路径，全部换成了环境变量。

`.gitignore` 默认挡住 `work/ assets/ cache/ out/ data/ frames/`、`vo/*/`、`music/*/` 和常见媒体格式。用自己的素材跑完之后，提交前再执行一次：

```bash
git status --short && git ls-files | grep -E "\.(mp4|mov|wav|jpg|png|json)$"
```
