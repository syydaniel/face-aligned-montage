# 02 教程：人脸对齐快剪

目标：几百段素材里同一个人的脸，跟着音乐快切，眼睛、鼻尖、嘴角、下巴始终在画面同一个位置。成片 4K 16:9，60 fps。

所有脚本都在 `pipeline/`，按编号顺序跑。脚本读 `MONTAGE_ROOT` 下的 `work/`、`assets/`、`cache/`，最后输出到 `MONTAGE_OUT`。

```bash
export MONTAGE_ROOT=~/montage && mkdir -p $MONTAGE_ROOT/{work/models,work/music,assets,cache,out}
bash scripts/download_models.sh
```

## 第 0 步：准备素材清单和参考脸

1. 把出镜的视频列成 CSV（`MONTAGE_SOURCES_CSV`）：

   ```text
   cid,path,dur,date,verdict
   0001,/path/to/clip_0001.mp4,12.4,2025-09-28,是我
   ```

   `cid` 是你自己定的短编号，`date` 用来保证相邻两刀不是同一天拍的，`verdict` 为 `是我` 的行才会被扫描。
2. 照片放在一个文件夹里（`MONTAGE_PHOTOS`），只支持 JPG。
3. 准备一张清晰的正脸照作为参考（`MONTAGE_REF_FACE`）。

## 第 1 步：生成叠加素材

```bash
python pipeline/00_overlays.py
```

生成裸眼 3D 用的横竖黑边（带 alpha）、暗角、暖色脉冲。全是程序生成，不涉及素材。

## 第 2 步：扫描人脸和身份过滤

```bash
for i in 0 1 2 3; do python pipeline/01_face_align.py $i 4 & done; wait     # 视频，4 个分片并行
for i in 0 1 2 3; do python pipeline/02_face_photos.py $i 4 & done; wait    # 照片
```

- 每段视频按时长抽 5 到 14 帧，YuNet 找脸，SFace 和参考脸比相似度。
- 视频阈值 0.30。照片阈值 0.32，并且只要画面里出现另一张不小的脸，整张照片就丢掉。
- 照片会被转成 1 秒 60 fps 的视频，因为 Resolve 的脚本接口给静帧设不了时长（见 05）。

输出 `work/face_align_*.json` 和 `work/face_photos_*.json`：每个素材的路径、分辨率、帧率、日期，以及候选帧的眼睛位置、眼距、角度、正脸度。

## 第 3 步：精细关键点和姿态

```bash
for i in 0 1 2 3; do python pipeline/03_pose.py $i 4 & done; wait
```

对每个候选帧跑 MediaPipe Face Landmarker：

- 取 13 个点：双眼虹膜中心、双眼内外眼角、鼻尖、两个嘴角、上下唇、下巴、眉心。
- 从变换矩阵算偏航、俯仰、翻滚。
- 从表情系数取张嘴（`jawOpen`）、微笑、眨眼。

结果写进 `work/pool_landmarks_*.json`。这一步不筛，门槛都在第 5 步和第 8 步。

## 第 4 步：标准脸和相似变换

标准脸是所有候选在"眼距单位、双眼水平、眼睛中点在原点"坐标系下的中位数形状，再放到 4K 画面上：

- 双眼中点在 (1920, 1000)，眼距 470 像素。
- 六个对齐点：双眼虹膜、鼻尖、两个嘴角、下巴。

每张脸用 Umeyama 算法求一个只含缩放、旋转、平移的变换，把六个点最小二乘贴到标准脸上。拟合残差（六点平均距离）超过 14 像素的直接丢掉，这通常意味着头偏了或者脸被遮挡。

## 第 5 步：闭环回测

```bash
python pipeline/04_qa.py
```

算出来的变换要换算成 Resolve 的 `ZoomX/Y、Pan、Tilt、RotationAngle`。这一步有很多坑（坐标方向、旋转中心、旋转正方向），只靠推导会偏。做法是：

1. 按 Resolve 的规则用 OpenCV 预合成一帧。
2. 在合成结果上重新跑关键点。
3. 把测到的偏差反推回参数，再合成、再测，来回几轮。
4. 最终误差超过 18 像素的候选丢掉。

结果写进 `work/pool_qa.json`。成片上的复测（第 13 步）眼睛偏差中位数在 12 到 18 像素（4K）。

## 第 6 步：曝光和白平衡

```bash
python pipeline/05_expo.py
```

在每张脸的皮肤区域测线性亮度和 RGB 比例，算出把它拉到统一亮度和肤色的增益。增益取 0.7 次方并限制在 0.75 到 1.5 之间，避免暗脸被拉成灰。写进 `work/pool_gain.json`，第 8 步会和风格调色（黑白、漂白、青橙）一起合进 CDL 的 slope。

## 第 7 步：配乐和节拍

```bash
ACESTEP_DIR=~/ACE-Step-1.5 ~/ACE-Step-1.5/.venv/bin/python pipeline/music/ace_run.py pipeline/music/jobs_trailer.json
ffmpeg -i <选中的 wav> -af loudnorm=I=-14:TP=-1 -ar 48000 $MONTAGE_ROOT/work/music/open_bgm.wav
python pipeline/three/score_from_audio.py $MONTAGE_ROOT/work/music/open_bgm.wav trailer   # 写 work/three/scores/trailer.json
```

- `jobs_trailer.json` 里有三种风格的提示词（phonk、混合预告片、bass house），每种两个种子。成片用的是 120 BPM 的混合预告片。
- 换了 job 名就设 `MONTAGE_SCORE_JOB`，剪辑表、砖墙、音效都按这个名字读节拍。
- `score_from_audio.py` 输出节拍、重音、强重音、落点、段落、RMS 和低频曲线。成片的落点在 8.76 秒。

## 第 8 步：剪辑表

```bash
python pipeline/09_bricks.py      # 先做砖块缩略图，剪辑表要用它们排脸部连续性
python pipeline/06_edl.py
```

`06_edl.py` 是核心。它先用宽松门槛（偏航和俯仰 14 度以内）建候选池，再上严格门槛：偏航和俯仰 8 度以内、张嘴不超过 0.35、眨眼不超过 0.35、拟合残差不超过 14 像素、回测误差不超过 18 像素。

**排序规则**

- 同一段素材 12 刀之内不重复。
- 相邻两刀尽量不是同一天拍的。
- 用 24×24 的脸部缩略图算相似度，让相邻两刀的脸看起来连续，像一个人在慢慢变。
- 按段落选表情：铺垫段偏中性，落点之后偏笑脸。

**段落结构**

| 段落 | 节奏 | 画面 |
|---|---|---|
| 铺垫（0 到 8.76 秒） | 八分音符，最后一小节十六分 | 第一刀全画幅；之后画面小，内接窗口从 0.62 长到 0.98；每三刀一个全画幅碎片；每九刀一个定格抖动；黑白；暖色脉冲代替白闪 |
| 落点后 | 十六分音符，强重音上三十二分 | 全画幅彩色；每四拍一次左右半脸拼贴；画中画只叠一个部位（先眼后嘴）；第 4 到 7 拍裸眼 3D |
| 高潮 | 三十二分音符 | 半脸裁切，色调轮换 |
| 结尾 | 十六分音符进入砖墙 | 一张脸裂成 2×2 直到 16×16，接 three.js 隧道和标题 |

**画中画和局部窗口**：所有窗口都定义在标准脸坐标里（右眼、左眼、嘴、鼻、半脸、眼带、嘴带），然后用 `CropRetain=True` 在输出坐标里裁切。画中画层用第 9 步做的逐像素对齐静帧，保证和底层五官完全重合。

输出 `work/open_cutlist.json`：每一刀的轨道、起始帧、长度、素材、源帧、变换、裁切、CDL、段落。

## 第 9 步：静帧、抠像

```bash
python pipeline/07_stills.py        # 画中画用的逐像素对齐 4K 静帧（1 秒视频）
python pipeline/08_mattes_fast.py   # IS-Net 快速蒙版，先出一版看效果
python pipeline/08_mattes_hq.py     # BiRefNet 高质量蒙版，替换快速版
```

快速版蒙版做了 5×5 腐蚀和 2 像素羽化，去掉边缘的一圈白边；高质量版头发边缘干净很多。

## 第 10 步：结尾

```bash
python pipeline/10_wall.py <最后一击的时间>     # 1 张脸按八分音符裂到 16×16，输出 assets/open_wall.mp4
mkdir -p $MONTAGE_ROOT/work/three && cp pipeline/three/bricks.html $MONTAGE_ROOT/work/three/   # 页面要从 MONTAGE_ROOT 提供
MONTAGE_ROOT=$MONTAGE_ROOT python pipeline/three/serve.py 8766 &
open "http://127.0.0.1:8766/work/three/bricks.html?capture=1&job=bricks"   # 逐帧捕获到 cache/three_bricks/
ffmpeg -framerate 60 -i $MONTAGE_ROOT/cache/three_bricks/%05d.jpg -c:v libx264 -crf 14 -pix_fmt yuv420p $MONTAGE_ROOT/assets/open_tunnel.mp4
python pipeline/11_title.py                    # 中英文标题，ProRes 4444 带 alpha
python pipeline/12_leaks.py                    # 漏光叠加层（不带划痕，见 04 的竖线事故）
```

`bricks.html` 的时间轴（秒）：

| 时刻 | 阶段 |
|---|---|
| 0 到 0.55 | 砖墙颤动 |
| 0.55 到 1.75 | 碎裂、物理下落、散落在地上 |
| 1.75 到 2.25 | 留白，什么都不动 |
| 2.25 到 3.3 | 碎片带着火花像粒子一样飞回，聚成环形 |
| 3.3 到 4.6 | 折成隧道，螺旋扭曲、径向模糊、色散 |
| 4.6 到 5.2 | 冲进虫洞，白场 |

标题在隧道开始后 4.9 秒出现，避开白场。

## 第 11 步：音效

```bash
python pipeline/13_sfx.py
```

全片音效都按剪辑表的帧合成：铺垫段每一刀一个轻点击、进落点和高潮的上升音、落点冲击、高潮特效刀上的数字故障声、裸眼 3D 段的上升音和低频敲击、砖墙裂开的点击声、碎裂、留白里只剩低频嗡鸣、重聚时的上升闪烁、虫洞呼啸、磁带停转、标题轰鸣。输出 `work/music/open_mix.wav`。

## 第 12 步：在 Resolve 里搭时间线

这些脚本要在 Resolve 进程里执行，需要全局变量 `resolve` 和 `project`。两种方式：

- 用 DaVinci Resolve 的 MCP 服务（`run_script_unsafe`），它会注入这两个变量。
- 或者在 Resolve 的 Python 控制台里：

  ```python
  import os; os.environ['MONTAGE_ROOT'] = '/path/to/montage'
  resolve = bmd.scriptapp('Resolve'); project = resolve.GetProjectManager().GetCurrentProject()
  exec(open('/path/to/pipeline/resolve/build.py').read())
  ```

顺序：

```python
exec(open('pipeline/resolve/build.py').read())                    # 建 OPEN 时间线：232 个片段，9 条视频轨
for c in [(0, 6), (6, 12), (12, 24)]:                              # Fusion 特效，每次最多 6 个合成
    CHUNK = c; exec(open('pipeline/resolve/fx.py').read())
for c in [(0, 8), (8, 16), (16, 24)]:                              # 裸眼 3D 的推拉动画
    CHUNK = c; exec(open('pipeline/resolve/fx3d.py').read())
exec(open('pipeline/resolve/final.py').read())                     # 4K H.265 渲染到 MONTAGE_FINAL
```

轨道分工：V1 人脸，V2 黑边，V3 抠像，V4 画中画，V7 暖色脉冲（Screen 28%），V8 漏光（Screen，铺垫 75%，结尾 22%），V9 暗角（Multiply 85%），V15 标题，A1 混音。

可选：`sapphire.py` 会复制一条 `OPEN_SAPPHIRE` 时间线并加上 Sapphire 节点。脚本渲染不了 OFX，这条要在 Deliver 页手动渲染。

## 第 13 步：成片复测

```bash
python pipeline/14_verify.py $MONTAGE_FINAL
```

在成片上逐刀测眼、鼻、嘴、下巴相对标准脸的偏差。偏差大的刀回到第 5 步重新定位，不一定要删掉。

## 常见问题

- **对不齐，而且偏差方向一致**：多半是 Tilt 的正负或旋转中心搞反了，看 05。
- **画中画和底层错位**：画中画层必须用第 9 步的逐像素对齐静帧，并且用输出坐标裁切。
- **渲染报 "Fusion composition could not be processed"**：时间线里有 OFX 节点或者不支持脚本渲染的 Fusion 工具，看 05 的白名单。
