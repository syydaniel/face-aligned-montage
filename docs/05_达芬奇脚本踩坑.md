# 05 DaVinci Resolve 脚本踩坑

以下全部在 DaVinci Resolve Studio 21.1（macOS）上实测。时间线 3840×2160，60 fps。

## 时间线和片段

| 现象 | 结论 |
|---|---|
| `MediaPool.AppendToTimeline` 的 `endFrame` | 是**开区间**。要放 `tf` 帧，写 `endFrame = startFrame + tf`。 |
| 静帧图片设 `endFrame` | 被忽略，长度是默认值。把照片转成 1 秒 60 fps 的视频再用。 |
| `recordFrame` | 是时间线的绝对帧号，要加上 `timeline.GetStartFrame()`。 |
| `AddTransition` 加 Smooth Cut | 两侧片段必须有源素材手柄，否则不生效。 |
| 删除时间线 | `MediaPool.DeleteTimelines([tl])`。 |
| 复制时间线 | `tl.DuplicateTimeline(name)`，Fusion 合成也会被复制。 |

## 变换属性（`TimelineItem.SetProperty`）

| 属性 | 实测含义 |
|---|---|
| `ZoomX` / `ZoomY` | 以画面中心缩放。 |
| `Pan` | 正值向右，单位是时间线像素。 |
| `Tilt` | **正值向上**，和图像坐标相反。按缩放后的位移算：`Tilt = ry * zoom + ty`。 |
| `RotationAngle` | **正值逆时针**，绕画面中心转。 |
| 组合顺序 | 先缩放和旋转（绕中心），再平移。推导时在中心坐标系里算，最后换回左上角坐标。 |

建议：别只靠推导。按这套规则用 OpenCV 预合成，再测关键点，偏差反推回参数（流水线第 5 步）。

## 裁切

| 设置 | 裁切值的含义 |
|---|---|
| `CropRetain = True` | 裁切值是**输出（时间线）坐标**，裁掉的部分留空，画面不重新居中。 |
| `CropRetain = False` | 裁切后画面会被重新居中，位置跟着变。 |

局部窗口（单只眼睛、嘴、半张脸）统一用 `CropRetain = True`，窗口定义在标准脸坐标里，直接就是输出坐标。

## 调色

- `TimelineItem.SetCDL({'NodeIndex': '1', 'Slope': 'r g b', 'Offset': '...', 'Power': '...', 'Saturation': 's'})` 可用。
- 每张脸的曝光增益直接乘进 slope，风格（黑白、青橙）用 saturation 和 power 叠。
- 抠像层要和底层用同一套 CDL，否则光对不上。

## Fusion 合成

- `item.AddFusionComp()` 新建；`comp.AddTool('Transform')` 加节点；`tool.Input = other` 连线。
- 关键帧：`tool[k] = comp.BezierSpline(); tool[k][frame] = value`。
- **一次脚本调用里最多处理 6 个合成。** 多了容易卡死或者让 Resolve 的脚本服务挂掉。用 `CHUNK = (a, b)` 分批。
- 脚本服务挂了（调用一直没返回）：退出 Resolve，结束残留的 `ResolvePython` 和 `fuscript` 进程再打开。

### 脚本渲染的白名单和黑名单

能被脚本渲染（`project.StartRendering`）的原生节点：

`Transform`、`DirectionalBlur`（含 Zoom 模式）、`ColorGain`、`Merge`、`Glow`、`Filter`（Sobel）、静态 `BrightnessContrast`、`FastNoise + Displace`、`Vortex`、`LensDistort`（`DEClassicLDModel.Distortion`）、`PseudoColor`、`FilmGrain`。

会让渲染报 "Fusion composition could not be processed" 的：

- 任何 OFX 插件，包括 Sapphire 和 ResolveFX。
- `Shake`。
- `TimeSpeed`。
- 带关键帧的 `BrightnessContrast`（做频闪）。
- 用 `RectangleMask` 做镜像的合成。

需要 OFX 效果时，复制一条时间线加上去，在 Deliver 页手动渲染。

## 插件加载（macOS）

Sapphire 这类 OFX 插件装好后提示无法打开（被隔离）：

```bash
sudo xattr -r -d com.apple.quarantine /Library/OFX/Plugins/<插件>.ofx.bundle
rm "$HOME/Library/Application Support/Blackmagic Design/DaVinci Resolve/OFXPluginCacheV2.xml"
```

然后重启 Resolve。只删缓存不去隔离属性，插件还是加载不了。

## 渲染

```python
project.SetRenderSettings({'SelectAllFrames': False, 'MarkIn': S, 'MarkOut': S + N - 1, 'TargetDir': out, 'CustomName': name,
                           'FormatWidth': 3840, 'FormatHeight': 2160, 'ExportVideo': True, 'ExportAudio': True})
project.SetCurrentRenderFormatAndCodec('mp4', 'H265')
job = project.AddRenderJob(); project.StartRendering(job)
```

- 渲染用的是**当前时间线**。改过别的时间线之后，记得 `project.SetCurrentTimeline(tl)` 切回来。
- 渲染是异步的。在外面轮询输出文件大小，连续两次不变再认为完成。
- 输出文件已存在时会覆盖，先把旧版本挪走留档。
