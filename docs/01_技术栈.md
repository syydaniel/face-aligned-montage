# 01 技术栈

整套东西跑在一台 Apple Silicon 的 Mac 上（MPS / MLX），没有用云端 API。下面按流水线顺序列出每个组件、它在这里干什么、为什么选它。

## 开场：人脸对齐快剪

| 环节 | 组件 | 在这里做什么 | 为什么选它 |
|---|---|---|---|
| 人脸检测 | OpenCV YuNet（`face_detection_yunet_2023mar.onnx`） | 每段视频抽 5 到 14 帧，找人脸和五个粗关键点 | CPU 上很快，自带眼睛和鼻尖，足够做第一轮粗筛 |
| 身份过滤 | OpenCV SFace（`face_recognition_sface_2021dec.onnx`） | 和一张参考正脸比余弦相似度，视频阈值 0.30，照片 0.32 | 只留本人；照片里有别人的脸就整张丢掉 |
| 精细关键点 | MediaPipe Face Landmarker（`face_landmarker.task`） | 478 个点（含虹膜）、52 个表情系数、头部姿态矩阵 | 虹膜中心比眼角稳定；表情系数直接给出眨眼和张嘴 |
| 对齐 | NumPy 实现的 Umeyama 相似变换 | 六个点（双眼虹膜、鼻尖、两个嘴角、下巴）最小二乘贴到一张标准脸 | 只有缩放、旋转、平移，不会把脸拉变形 |
| 闭环回测 | OpenCV `warpAffine` + 再次检测 | 按 Resolve 的变换规则预合成一帧，再测一遍，把误差反推回参数 | 计算值和软件里实际渲出来的位置会有偏差，必须用结果说话 |
| 曝光白平衡 | NumPy | 测脸部皮肤的线性亮度和 RGB 比例，算每张脸的增益 | 写进 Resolve 的 CDL slope，不需要手动调色 |
| 抠像 | BiRefNet（经 rembg），快速版用 IS-Net | 裸眼 3D 段的人像蒙版，ProRes 4444 带 alpha | BiRefNet 头发边缘最干净；IS-Net 快，用来先出一版 |
| 配乐 | ACE-Step 1.5（XL SFT，MPS） | 生成 120 BPM 预告片风格配乐，8.76 秒有落点 | 本地、可控 BPM 和调式、可批量出多版挑 |
| 节拍 | librosa | 节拍、重音、落点、低频能量曲线 | 剪辑点全部来自音频分析，不靠手点 |
| 剪辑 | DaVinci Resolve Studio 21 脚本 API | 建时间线、放片段、设缩放平移旋转裁切、CDL、转场 | 4K 调色和渲染质量好，脚本能控制到每一帧 |
| 特效 | Resolve Fusion 原生节点 | 缩放模糊、RGB 分离、霓虹描边、数字撕裂、旋涡、镜头畸变、颗粒、3D 推拉 | 原生节点能被脚本渲染；OFX 插件不行（见 05） |
| 结尾 | three.js r16x + 自写着色器 | 砖墙颤动、碎裂下落、留白、粒子重聚、隧道、虫洞扭曲 | 物理和粒子用代码写比在剪辑软件里拼更可控 |
| 逐帧捕获 | 浏览器 `toBlob` + 本地 POST 服务器 | three.js 场景按帧渲染成 JPG 序列 | 确定性，和实时帧率无关 |
| 标题 | Pillow + ffmpeg | 中英文标题动画，ProRes 4444 带 alpha | 字体排版完全可控 |
| 音效 | NumPy 合成 | 节拍瞬态、上升音、落点冲击、碎裂、低频嗡鸣、虫洞呼啸、标题轰鸣 | 每个音效都对齐到剪辑表里的帧 |

## 讲解视频

| 环节 | 组件 | 在这里做什么 |
|---|---|---|
| 文案检查 | `explainer/tools/ai_flavor.py` | 扫中文稿里的空词、套话、对立句、排比、四字词扎堆、破折号 |
| 配音 | Qwen3-TTS 1.7B Base（mlx-audio，bf16） | 用一段参考音频克隆音色，逐句生成，每句最多三次 |
| 配音质检 | Whisper large-v3-turbo（mlx-whisper） | 识别每次生成的结果，和原文比相似度，挑最准的；数字先转成汉字再比 |
| 配乐 | ACE-Step 1.5 | 230 秒、92 BPM 的纪录片式底乐 |
| 渲染 | 单个 HTML 文件，Canvas 2D | 20 个场景，所有动画都是时间的纯函数 |
| 捕获 | Playwright（`playwright-core`）驱动系统 Chrome | 6 个页面并行，约 40 帧每秒，3 分钟出完 7884 帧 |
| 混音 | NumPy + SciPy + pyloudnorm | 每句 -17 LUFS、人声躲避、开场原声同步、留白、合成音效、总线 -16 LUFS |
| 封面 | Pillow | 9:16、3:4、2.35:1、1:1 四种 |

## 运行环境

- macOS 14 以上，Apple Silicon，建议 32 GB 内存以上（ACE-Step XL 和 Qwen3-TTS 同时跑时占用大）。
- Python 3.11 到 3.12 用于 MediaPipe 和 rembg；mlx-audio 和 mlx-whisper 最好单独一个环境。
- ffmpeg 7 以上（需要 `prores_ks`、`libx264`）。
- Node 18 以上和本机 Google Chrome（Playwright 用 `channel: 'chrome'`，不需要下载浏览器）。
- DaVinci Resolve Studio（免费版的脚本外部调用受限）。

## 替代方案

- 不用 Resolve：开场所有变换都在剪辑表里，可以改写成 ffmpeg 的 `filter_complex` 或者全部放进 canvas 渲染器，但调色和 4K 渲染质量要自己补。
- 不用 MediaPipe：dlib 68 点也能做六点对齐，但没有虹膜和表情系数，闭眼和张嘴要自己从点距算。
- 不用本地 TTS：任何能克隆音色的 TTS 都行，保留"多次生成 + 识别打分"这一步。
